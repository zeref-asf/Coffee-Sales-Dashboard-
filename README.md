
# ☕ Coffee Sales Dashboard

An interactive sales dashboard created in Microsoft Excel to analyze coffee sales performance across different countries, products, customers, and time periods.

## 📊 Dashboard Preview

[Coffee Sales Dashboard](Dashboard_Preview.png)

## 🎯 Business Objective

The objective of this project was to transform raw coffee sales data into an interactive dashboard that can help identify:

- Sales trends over time
- Top-performing countries
- Top customers
- Product performance
- Impact of coffee size and roast type
- Loyalty card sales patterns

## 🛠️ Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Conditional Formatting
- Dashboard Design

## 📈 Key Dashboard Features

- Total sales over time
- Sales by country
- Top 5 customers
- Product/coffee type analysis
- Interactive date filtering
- Size filtering
- Roast type filtering
- Loyalty card filtering

## 💡 Key Insights

The dashboard allows users to interactively filter the data and identify trends in coffee sales performance across different dimensions.
